# Socket.IO Chat App

A simple real-time chat application built using **Node.js**, **Express**, and **Socket.IO**. This app allows users to send and receive messages instantly across connected clients in the browser.

## 🚀 Features

- Real-time messaging using WebSockets (Socket.IO)
- Broadcasts messages to all connected users
- Self-sent messages styled differently for better UX
- Clean, responsive UI using vanilla HTML/CSS

## 🛠️ Tech Stack

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [Socket.IO](https://socket.io/)
